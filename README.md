# JobApplicationTool

Chrome extension (**ApplyKit**) to autofill job applications, match resumes to job descriptions, and send tailored application emails—with your profile stored locally.

**Repository:** [KumarMohit85/JobApplicationTool](https://github.com/KumarMohit85/JobApplicationTool)

## Quick start

```bash
git clone https://github.com/KumarMohit85/JobApplicationTool.git
cd JobApplicationTool/applykit
npm install
npm run build
```

Load the `applykit/dist` folder in Chrome at `chrome://extensions` (Developer mode → Load unpacked).

See **[SETUP.md](./SETUP.md)** for full steps, prerequisites, and troubleshooting.
